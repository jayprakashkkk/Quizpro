# BCA Quiz Pro 🎓

A focused, interactive practice web application for BCA (Bachelor of Computer Applications) students.

## 🚀 Live Site
- Netlify: [https://quizpro-webapp.netlify.app](https://quizpro-webapp.netlify.app)

## ✨ Features
- **Student Authentication**: Secure client-side persistent login and account creation (stored in browser local storage).
- **Multiple Subjects & Mixed Mode**:
  - Web Technologies
  - Database Management Systems (DBMS)
  - Operating Systems
  - Computer Networks
  - Programming in C / C++ / Java
  - All Subjects (Mixed Practice)
- **Practice & Timed Quiz**: Randomized questions, instant answer feedback, and detailed explanations.
- **Progress & Attempts History**: Tracks previous attempts, scores, and percentage breakdown.
- **Theme Support**: Seamless Dark Mode and Light Mode switching.
- **Mobile Responsive**: 100% full-screen adaptive UI optimized for smartphones, tablets, and laptops.

## 🛠️ Tech Stack
- React
- Vite
- Modern Vanilla CSS with CSS Variables
- Client-Side Persistent Storage (`localStorage`)
- Netlify Edge Hosting

## 📦 Deployment
This repository is pre-built and ready to deploy on **Netlify**, **Vercel**, or **GitHub Pages** without requiring any build step.
